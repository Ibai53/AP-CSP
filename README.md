# AP-CSP
This repository contains a few of the largest projects that I worked on during my AP CSP class at Jones College Prep. All of the code is in Python and written by me.

IMDB.csv: Dataset for the movie.py function

Madlibs: This program creates a Mad Libs story and allows users to use random inputs if they want.
Movie: Final create task for AP CSP. This program uses IMDb's top 1000 movies to allow users to filter through the movies using many filters.
Pokémon: This program runs a small Pokémon game, which allows the user to do things like fight and train their Pokémon.
RPS: This program allows the user to play rock, paper, scissors against the computer.
Search: This program simulates linear and binary sorts to show the speed difference as the data set gets larger.
Simulation: This program runs thousands of simulations of a race between a tortoise and a hare.
Slot: This program allows the user to use a slot machine and also save their progress to a text file using their name.
